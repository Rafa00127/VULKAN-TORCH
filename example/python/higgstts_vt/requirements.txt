# Third-party deps for the HiggsTTS example.
#
# vulkantorch itself is NOT installable from here: it is not on PyPI and there
# is no pyproject.toml. Build it first, then put the repo root on sys.path
# (see sharing_docs/how-to-write-code.md):
#   Windows    python build_win.py
#   Linux/WSL  sh build.sh
# Both emit into build/, and the extension into vulkantorch/ (the source dir).
# Either needs pybind11 -- without it CMake warns and skips the python module.
# Only 3.12 has actually been tried; other versions should work too -- the
# extension is built for whichever interpreter runs the configure step.
numpy
librosa
tokenizers
